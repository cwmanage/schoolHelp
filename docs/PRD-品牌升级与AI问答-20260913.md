## 2. 需求二：AI 侧边问答（免费大模型）

### 2.1 可行性结论

- 免费网站（无开放 API）无法直接传对话；**采用免费大模型 API，效果等同**。
- 选型 **智谱 GLM-4-Flash**：完全免费（不限量，仅 30 QPS 限速）、OpenAI 兼容、国内直连、中文强。备选：硅基流动（9B 以下模型永久免费）。
- ⚠️ **需要用户操作**：到 `bigmodel.cn` 注册 → 创建 API Key（免费）。key 未配置前功能提示「未配置」。

### 2.2 交互设计

- 两端登录后显示**右下角浮动圆钮**（机器人图标）；未登录不显示。
- 点击打开对话抽屉（PC 右侧 420px 抽屉 / 移动端近全屏），含欢迎语、消息气泡、输入框、清空按钮。
- 多轮：携带最近 6 条历史做上下文；历史存 localStorage（按用户区分），刷新不丢。
- 非流式返回（第一版）：发送后 loading 动画，60s 超时提示稍后再试。

### 2.3 后端实现

- `user` 服务新增 `AiController`（`POST /api/user/ai/chat`，走网关 JWT 鉴权，**不加白名单**，防滥用）。
- `AiService` 用 RestClient 转发智谱 OpenAI 兼容接口（`/api/paas/v4/chat/completions`，model `glm-4-flash`）；system prompt 限定为校园学习助手。
- 配置注入：`ai.base-url` / `ai.api-key` / `ai.model`，key 为空时返回明确提示；服务器经 `.env` 注入 `SCHOOLHELP_AI_API_KEY`。
- 简单限流：每用户每分钟 5 次（内存计数），超限提示。
- 用户输入长度上限 1000 字符。

### 2.4 验收

- [ ] 登录后浮动按钮可见，未登录不可见
- [ ] 多轮对话回答正常，历史刷新保留
- [ ] 未配置 key 时给出友好提示，不影响其他功能
- [ ] 限流生效

## 3. 需求三：七天免登录（滑动续期）

### 3.1 现状

- JWT 有效期已 7 天（`JwtUtil` 写死），token 已存 localStorage（关浏览器不丢）。
- **缺口**：固定 7 天过期，第 8 天访问必掉线；无续期机制。

### 3.2 方案：滑动续期

- 网关 `AuthGlobalFilter`：校验通过后，若 token 剩余有效期 **< 3 天**，重签新 7 天 token，写入响应头 `X-Renewed-Token`（对前端透明，不改变任何现有接口行为）。
- 前端两端 `request.js` 响应拦截器：检测到 `x-renewed-token` 即 `setToken()` 更新。
- **效果**：只要 7 天内访问过一次，登录态一直有效；连续 7 天不访问才需要重新登录。阈值 3 天/有效期 7 天可后续再调。

### 3.3 验收

- [ ] 用「剩余 <3 天」的 token 请求任意接口，响应头带新 token，前端自动更新
- [ ] 新签 token 请求正常，旧 token 未过期前仍可用
- [ ] 登录/注册等白名单接口不受影响
